# 🏥 Hospital Emergency Room Dashboard

## 📊 Project Overview
This project analyzes hospital emergency room data using Microsoft Excel. The dashboard provides insights into patient admissions, waiting time, satisfaction scores, age groups, gender distribution, and department referrals.

## 🛠️ Tools & Technologies
- Microsoft Excel
- Power Query
- Power Pivot
- Excel Formulas & Calculated Columns
- PivotTables & PivotCharts
- Interactive Dashboard

## 🔄 Project Workflow
1. Imported the hospital dataset from a CSV file.
2. Cleaned and transformed data using Power Query.
3. Created table relationships using Power Pivot Diagram View.
4. Added calculated columns and updated data using formulas.
5. Analyzed the data using PivotTables.
6. Created a dashboard with KPI cards, charts, and monthly filters.

## 📈 Key Performance Indicators
- Total Number of Patients
- Average Waiting Time
- Patient Satisfaction Score
- Admission Status Analysis
- Age Group Distribution
- Gender-wise Patient Analysis
- Department Referral Analysis
